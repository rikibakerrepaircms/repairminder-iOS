## Non-negotiable conventions (from Phases 1–3 — do not re-derive)
- Networking: shared `APIClient` — `request<T>(_:body:)` (POST/PUT/PATCH with `Encodable` body; also for responses nested under `data`), `requestVoid` (DELETE), **`requestFull<R>`** ONLY when you need envelope-sibling fields the shared `APIResponse<T>` drops (Phase 2 edit/allocate did; Phase 3 did NOT). Encoder `.convertToSnakeCase`; small `Codable` request structs; camelCase; NO explicit CodingKeys; every optional request property `= nil`; struct field order = labeled call-site order.
- Add endpoints to `APIEndpoint` (case + `path` + `method` group + `queryItems` + default `requiresAuth==true`). Verify line numbers by grepping — don't trust stale numbers.
- Models: `Decodable, Identifiable, Equatable, Sendable`; Int-booleans as `Int?` + computed `Bool`; enums `UnknownDefaultable`; comma-joined strings stay `String`. Reuse `Asset`, `InventoryGroup`, `AssetQuery`.
- **Errors:** `APIError.serverError(message, code: String?)` (code is a semantic string, 200-with-success:false) vs `APIError.httpError(statusCode: Int, message: String?)` (non-2xx). NO `userMessage` — use `error.localizedDescription`. Map HTTP-409/400 by `httpError` statusCode and/or message text, not by `code`.
- `@MainActor` init trap: never a `@MainActor` `.shared`/`InventoryService()` as a DEFAULT-ARG value → `init(x: T? = nil) { self.x = x ?? T.shared }` (SwiftUI `View` stored-property defaults are fine).
- Views: `isEmbedded` contract (embedded body owns no `NavigationStack`); sheets show their OWN inline error (a parent `.alert` won't present over a sheet); post `.inventoryAssetDidChange` after any mutation so list/detail refresh; distinct `Identifiable` route wrappers to avoid `navigationDestination(item:)` type collisions; extract testable gating into a pure helper (`AssetActions`/`GroupActions` pattern). Extract row subviews when a `ForEach` closure has nested `if let`.
- Tests: subclass the shared `InventoryServingStub` and override only what you need; add the new protocol methods' stubs to it (and any other conformer the compiler flags).
