## Non-negotiable conventions (from Phases 1–2 — do not re-derive)
- Networking: shared `APIClient` — `request<T>(_:body:)` for POST/PUT/PATCH with an `Encodable` body; `requestVoid` for DELETE; **`requestFull<R>`** when you need envelope-level fields the shared `APIResponse<T>` drops (bulk-assign returns `{groups_added, groups_removed, assets_affected, sibling_match, …}` as envelope siblings — likely needs `requestFull`). Encoder is `.convertToSnakeCase`; small `Codable` request structs, camelCase fields, NO explicit CodingKeys. Give every optional request-struct property `= nil`, and order struct fields to match labeled call-site order.
- Add endpoints to `APIEndpoint` (case + `path` + `method` group + `queryItems` + default `requiresAuth==true`). Verify current line numbers by grepping — don't trust stale numbers.
- Models: `Decodable, Identifiable, Equatable, Sendable`; NO snake_case CodingKeys; Int-booleans as `Int?` + computed `Bool`; enums use `UnknownDefaultable`; comma-joined `group_names`/`group_ids` are STRINGS not arrays. Reuse `Asset`, `AssetGroupSummary`, `AssetGroupListItem`, `ExternalDeploymentRecord`.
- @MainActor init trap: never use a `@MainActor` singleton (`APIClient.shared`, `InventoryService()`) as a DEFAULT-ARG value → `init(x: T? = nil) { self.x = x ?? T.shared }`. (SwiftUI View stored-property defaults are fine.)
- Views: `isEmbedded` contract (embedded body owns no NavigationStack — the More stack provides it). Sheets must show their OWN inline error (a parent `.alert` won't present over a sheet). Post `.inventoryAssetDidChange` after any mutation that changes an asset's groups so list/detail refresh; extract testable gating into a pure helper like `AssetActions`.
- Backend field gotchas already burned: `Order` uses `orderNumber` (Int) not `ticketNumber`; `OrderStatus` display is `.label` not `.displayName`; delete blocks with **HTTP 400** not 409; `assets.checked_out_to_order_id` has an FK.
